# botc-sheet

Player reference sheet for a Blood on the Clocktower storyteller helper. The link carries the script (character ids) in its `#` part; nothing about a game is ever sent here.

Not an official page. Character data and art come from the toolmaker resources of https://github.com/ThePandemoniumInstitute/botc-release and are used under the [Community Created Content Policy](https://bloodontheclocktower.com/pages/community-created-content-policy), for personal, non-commercial use.

`python build.py` regenerates `db.json` and `icons/` from the app assets.
